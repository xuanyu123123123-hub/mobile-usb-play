비공식 초기 프로필

아래 버튼의 가상 터치 위치를 수정할 수 있어. 축구장 위의 동그라미를 드래그하거나 좌표를 바꾸면 돼. 실제 FC 모바일 버튼 위치는 연결 후 확인해야 해. 기존 오른쪽의 키보드 설정이 이 프로필에 반영돼.

새 기능: 프로필 저장하고 열기를 누르면 같은 사이트의 미러링 엔진에 이 프로필을 등록해. 엔진에서 Profiles 탭으로 이동해 FC 모바일 시작용 프로필을 선택하고 Play 모드를 켜면 돼. 위치는 실기기 화면을 보면서 다시 맞춰야 해. 같은 브라우저·같은 사이트 주소에서만 저장 상태가 공유돼.

설정 준비 완료 · 아직 실제 게임 입력을 테스트하지 않았어.

화면 설정 (저장됨)

지금은 선호도만 저장해. 실제 스트리밍 품질에 적용하려면 미러링 엔진과 연결해야 해.

키보드 설정

키 버튼을 누른 뒤 원하는 키를 입력해. 설정은 이 브라우저에 자동 저장돼.
